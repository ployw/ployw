## 🔬 What I'm currently working on

I'm finishing up my senior capstone: an **AI-assisted patient triage system** built for an ENT clinic in Lake Tahoe. My team worked directly with clinic schedulers and staff to understand the real challenges in patient triaging, and built a system to help.

The stack includes a **FastAPI** backend, a **React** dashboard for clinic staff to review cases and AI decisions, **PostgreSQL/RDS** for data, an automated phone intake agent via **Amazon Lex**, and a fine-tuned **Ollama** model that classifies urgency and generates case summaries from call transcripts.

`React` `FastAPI` `PostgreSQL` `Amazon Lex` `Ollama` `Google Calendar API`
